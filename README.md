# InvestControl

Projecto front-end em HTML, CSS e JavaScript puro (sem build).

## Como correr no VS Code
1. Abre a pasta `investcontrol` no VS Code (Ficheiro > Abrir Pasta).
2. Instala a extensão **Live Server** (Ritwick Dey).
3. Botão direito em `index.html` > **Open with Live Server**.

(Também funciona abrindo `index.html` directamente no browser. Precisa de internet para as fontes.)

## Estrutura
- `index.html` – estrutura e navegação
- `css/style.css` – estilos (cores e tipografia do DESIGN.md do Stitch)
- `js/data.js` – dados de exemplo
- `js/app.js` – ecrãs, filtros, modal, rotas (#movimentos, #investimentos, #definicoes...)
